# 前端

`web/index.html`：單一 HTML 檔，由後端 `GET /` 提供，沒有建置步驟。

## 版面

- 頂列：產品名、「示範資料，內容皆為虛構」標示、角色下拉。角色代碼存 `localStorage`（鍵 `selfservice-bi-role`），每個 API 呼叫都帶 `X-Viewer`。
- 頂列右側：資料基準日、資料時間（目前儀表板所有卡片最早的 `meta.dataTime`）、「重新整理」（送 `X-Refresh: 1`，前端 60 秒內再按只提示剩餘秒數）。
- 左側選單：**儀表板**（角色儀表板與個人版、自建儀表板）、**報表**（我的報表、新增報表）、**管理**（管理員才顯示）。
- 寬度 ≤ 768px：選單收進頂列 ☰，工具列換行，卡片一欄一張。

## 角色儀表板與個人版

- 非管理員編輯角色儀表板並儲存 → 後端存成個人版，選單標「已調整」。
- 角色儀表板上改日期或客戶篩選：非管理員只在這次瀏覽有效，不另存個人版。
- 個人版頁頂有「還原成角色預設」（`POST /api/dashboards/<角色版 id>/restore`）。
- 管理員的「角色儀表板管理」：派給角色、開啟／編輯／複製／刪除、各角色首頁（`PUT /api/role-home`）。刪除角色儀表板時，主管的個人版保留並變成一般個人儀表板。
- 共用報表（`shared: true`）：非管理員看到「另存一份」取代「編輯」。

## 圖表選項

圖表設定的「進階選項」與儀表板編輯模式卡片的「選項」用同一份表單（`optsFormHtml`／`readOpts`／`optsFor`）：排序、只顯示前 N 項、累計占比（長條圖）、與前 N 期平均比（指標卡）、卡片期間（全部）。

## 資料流

| 前端動作 | API |
|---|---|
| 預覽報表（先在前端驗證，通過才送） | `POST /api/run` |
| 儀表板每張卡、圖表預覽 | `POST /api/chart` |
| 下鑽（一次取回，分頁與排序在前端） | `POST /api/drill` |
| 可用圖表類型 | `POST /api/chart-options` |
| 欄位目錄 | `GET /api/meta` |
| 儲存內容 | `GET /api/state` 與 reports／dashboards CRUD |

驗證與標籤格式的規則留在前端 `<script id="engine">`，後端 `engine.ts` 再驗一次。
