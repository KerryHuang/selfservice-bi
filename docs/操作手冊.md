## 1. 畫面介紹

| 位置 | 內容 |
|---|---|
| 頁首左邊 | ☰（窄螢幕開關選單）、系統名稱、**角色下拉選單**（業務主管／生產主管／採購主管／老闆／管理員） |
| 頁首右邊 | 資料基準日與資料時間、**重新整理** |
| 左側選單「儀表板」 | 你看得到的儀表板（首頁標「★ 首頁」、調整過的標「已調整」），以及「＋ 新增儀表板」 |
| 左側選單「報表」 | 我的報表、新增報表 |
| 左側選單「管理」 | 角色儀表板管理（只有管理員看得到） |

### 切換角色

在頁首的角色下拉選單選一個角色，畫面會跳到該角色的首頁。

- 示範站沒有登入，切換角色就是換身分，可以用來看不同主管看到的畫面。
- 正在編輯儀表板、還沒存檔時，不能切換，要先按「完成」或「取消」。

### 各角色的首頁

| 角色 | 首頁 |
|---|---|
| 業務主管 | 營運總覽 |
| 生產主管 | 生產總覽 |
| 採購主管 | 採購總覽 |
| 老闆 | 經營總覽 |
| 管理員 | 沒有首頁；從左側選單或「角色儀表板管理」開啟 |

## 2. 看儀表板

### 2.1 卡片類型

| 類型 | 看什麼 |
|---|---|
| 指標卡 | 一個大數字。有設比較時，旁邊用 ▲／▼ 顯示比前幾週（月）平均高或低多少 |
| 長條圖 | 分類比較或排行。有「累計占比」時多一條百分比折線 |
| 折線圖 | 隨時間的變化 |
| 圓餅（環圈）圖 | 占比 |
| 表格 | 明細或彙總清單 |

每張卡片底部有：

- 本圖依哪個日期欄位篩選、資料時間
- **來源**：產生這張圖的報表名稱
- **開啟「X」→**（有設定時）：跳到相關的儀表板，例如老闆頁的「本月採購金額」連到採購總覽

### 2.2 篩選

儀表板上方的篩選列可以改**日期區間**、**客戶**、**訂單類型**，所有卡片一起套用。

- 篩選和每張報表自己的條件取交集，不會改動報表。
- 某張卡片不適用某個篩選（例如採購卡片沒有「客戶」）時，卡片會標「未套用：客戶」。
- 有些卡片有自己的期間（例如「上週完工零件數」固定看上週），不跟著頁首日期變。
- 在**角色儀表板**上改篩選只在這次瀏覽有效，離開或重新整理就回到預設，不會影響別人，也不會產生個人版。
- 按「清除篩選」回到預設。

### 2.3 下鑽看明細

1. 點長條、折線上的點、圓餅區塊或指標卡。
2. 進入「下鑽明細」頁，列出組成這個數字的每一筆資料；上方顯示套用了哪些條件、點選的是哪個分類。
3. 想看這張卡全部（不限點選分類）的明細，按「清除點選分類」或「查看全部明細」。
4. 按「返回儀表板」回去。

明細最多顯示 2,000 筆，超過時會提示「只顯示前 2,000 筆（共 N 筆）」；上方合計仍是整體的值。要看其餘明細，請縮小篩選或報表條件。

### 2.4 重新整理

查詢結果會保留 10 分鐘，大家共用。

- 要看最新數字，按頁首右邊的「重新整理」。
- 每人每分鐘只能真正重查一次。太快再按會跳出提示，畫面顯示的仍是上一次的結果。
- 頁首的「資料時間」是目前畫面上最舊的那份資料是幾點從資料庫抓的。

## 3. 調整自己的儀表板

### 3.1 個人版是什麼

角色儀表板由管理員預先建好。你對它做的任何調整（改名、換卡片、改排序或選項），都會**另存成你的個人版**：

- 左側選單標「已調整」，頁首標「已調整（個人版）」。
- 只有你看得到，不影響同角色的其他人。
- 管理員之後更新角色儀表板時，**不會覆蓋**你的個人版。你會看到提示「角色儀表板已更新」，自己決定要不要還原（見 3.5）。

### 3.2 改名

1. 打開儀表板，按右上角「改名」。
2. 輸入新名稱，按「改名」。

角色儀表板改名後會變成你的個人版。

### 3.3 編輯卡片

1. 打開儀表板，按右上角「編輯」。頁首會標「編輯中・尚未存檔」。
2. 可以做的事：

   | 操作 | 方法 |
   |---|---|
   | 調整順序 | 拖曳卡片，或按卡片上的 ↑ ↓ |
   | 改尺寸 | 卡片上選 小／中／大 |
   | 改選項 | 按卡片上的「選項」（見 3.4） |
   | 移除卡片 | 按「移除」 |
   | 新增卡片 | 按「＋ 新增圖表」（見第 5 節） |

3. 按「完成」存檔；按「取消」全部還原成編輯前的樣子。

### 3.4 卡片選項

編輯模式下按卡片上的「選項」：

| 選項 | 說明 | 適用 |
|---|---|---|
| 卡片期間 | 跟隨儀表板篩選，或固定為本週、上週、近 8 週、本月、上月、近 3 個月、近 12 個月、今年 | 全部 |
| 排序 | 依分類、由大到小、由小到大 | 長條圖 |
| 只顯示前 N 項 | 例如稼動率最閒 10 台 | 長條圖 |
| 顯示累計占比 | 多一條累計百分比線，看前幾名占多少；百分比的分母是全部分類 | 長條圖（加總類指標） |
| 與前 N 週／月平均比較 | 指標卡旁顯示 ▲／▼ 與百分比 | 指標卡 |
| 點了開啟儀表板 | 卡片底部出現連結 | 全部 |

### 3.5 還原成角色預設

在個人版上按「還原成角色預設」並確認：你的個人版會被刪除，改看管理員最新的角色儀表板。**你的調整會捨棄。**

### 3.6 自己的儀表板

在角色儀表板之外，也可以建立只有自己看得到的儀表板：按左側選單「儀表板」區最下方的「＋ 新增儀表板」，輸入名稱後直接進入編輯。

## 4. 自己組報表

左側選單「報表 → 新增報表」，或在「我的報表」按「＋ 新增報表」。設計器分五步，可以來回切換，填過的內容不會遺失。「下一步」按不下去時，按鈕旁會寫原因。

### 步驟 1：選擇資料

選一個主題，例如「採購明細」。畫面會寫明「每一列代表」什麼，這決定了數字怎麼加。

需要時勾選**相關資料**，例如採購明細加上「收料結果」，才會出現收齊、實交日、交期狀態等欄位。加入相關資料不會讓列數變多。

### 步驟 2：選擇欄位

從左邊「可選欄位」按「＋ 加入」，右邊「已選欄位」可以用 ↑ ↓ 排順序、✕ 移除、另取顯示名稱。上方可以搜尋欄位名稱。

### 步驟 3：設定條件（選做）

按「＋ 新增條件」，例如「訂購日＝近 3 個月」「交期狀態＝逾期未到」。多個條件可以選「全部條件」（且）或「任一條件」（或）。

### 步驟 4：分組與彙總（選做）

- **明細表**：一列一筆資料。
- **彙總表**：選分組欄位（最多 2 個，日期可選依日／週／月），再按「＋ 新增指標」選彙總方式，例如「依供應商分組，加總本幣金額」。

比率類指標（達交率、供應商準時率、稼動率、工令進度、製程完工比）會在每個分組重新計算，不是把各列加起來。用到需要相關資料的比率時，若步驟 1 沒勾，畫面會提示並提供一鍵修正。

原幣金額、數量不能跨幣別／單位加總；被擋下時畫面會提供「加入幣別分組」或「篩成單一幣別」等一鍵解法。

### 步驟 5：預覽與儲存

看結果（可翻頁、按「重新整理預覽」），確認後按「儲存報表…」，輸入報表名稱。

### 我的報表

| 按鈕 | 作用 |
|---|---|
| 開啟 | 看報表結果 |
| 編輯 | 回到設計器修改（只有自己的報表） |
| 圖表／設定圖表 | 把報表做成圖表（第 5 節） |
| 複製／另存一份 | 複製一份自己的版本。共用報表只有管理員能改，其他人要調整就「另存一份」 |
| 刪除 | 刪除報表。被任何儀表板引用中的報表不能刪，要先移除那些卡片 |

## 5. 把報表做成圖表、放進儀表板

### 從報表開始

1. 在「我的報表」或報表預覽頁按「圖表」（或「設定圖表」）。
2. 在「圖表設定」選：
   - **圖表類型**：表格、指標卡、長條圖、折線圖、圓餅（環圈）圖
   - **分類欄位**：長條／折線／圓餅用；日期欄位可選依日、週、月
   - **數值指標（彙總方式）**
   - **套用儀表板日期篩選的日期欄位**：放進儀表板後，頁首日期要篩哪個日期
   - 指標卡可以另取「指標卡名稱」與「單位」
   - **進階選項**：同 3.4 的卡片選項
3. 圖表不能畫時畫面會說明原因，並提供「回報表步驟 2／4」修正。例如圓餅圖不接受負數、分類最多 8 項、只能用可加總的指標（比率、平均、最大、最小都不適用）。
4. 按「加入儀表板…」，選要加入哪個儀表板（或新建一個）、填卡片標題、選尺寸，確認。

### 從儀表板開始

1. 打開儀表板，按「編輯」→「＋ 新增圖表」。
2. 選一份已儲存的報表，按「前往圖表設定」，接著同上。
3. 回到儀表板後按「完成」存檔。

圖表的數字直接取自報表。改報表，所有用到它的圖表都會跟著變。

## 6. 管理員

在頁首把角色切成「管理員」。

### 6.1 角色儀表板管理

左側選單「管理 → 角色儀表板管理」，列出所有角色儀表板：

| 操作 | 說明 |
|---|---|
| ＋ 新增角色儀表板 | 輸入名稱並勾選要派給哪些角色（至少一個），建好後直接進入編輯 |
| 開啟／編輯 | 看或編輯卡片 |
| 改名 | 改名稱 |
| 複製 | 複製一份新的角色儀表板，可另選派給的角色 |
| 刪除 | 派給的角色從此看不到；**主管已調整的個人版會保留**，變成他們自己的儀表板 |
| 派給角色 | 每一列的角色勾選框，直接修改 |

管理員修改角色儀表板（包括改名）並存檔後，已調整過的主管會看到「角色儀表板已更新」提示，可以自己選擇還原。沒調整過的主管直接看到新版。

管理員在角色儀表板上改頁首篩選也只是暫時看看，不會存檔。要改**預設篩選**，請按「編輯」→ 改篩選 →「完成」。

### 6.2 設定各角色的首頁

在「角色儀表板管理」上方的「各角色的首頁」，每個角色選一份派給它的角色儀表板。

### 6.3 共用報表

管理員儲存報表時勾「設為共用報表」：

- 所有角色都看得到，可以放進角色儀表板。
- 只有管理員能修改；其他人要調整就「另存一份」。
- 預設的四份角色儀表板用的都是共用報表。

### 6.4 重設自建內容

畫面上沒有重設按鈕。要把報表、儀表板、首頁全部還原成出廠狀態（會清掉所有自建內容與個人版），請依 [`README.md`](../README.md)「重設自建內容」執行。

## 7. 常見問題

| 狀況 | 原因與處理 |
|---|---|
| 卡片顯示「來源報表已被刪除」 | 報表被刪除或不再共用。按「移除」拿掉卡片，或請管理員重建報表 |
| 卡片顯示欄位已不存在 | 報表用到的欄位被移除，回報表修正 |
| 「分組結果超過 500 組」 | 縮小日期區間、加條件，或改用較粗的分組（例如日期改依月） |
| 「只顯示前 2,000 筆」 | 明細上限。加條件縮小範圍，或改用彙總表 |
| 按「重新整理」數字沒變 | 一分鐘內重複按會被略過（畫面會提示），或資料本來就沒有變動 |
| 比率顯示「—」 | 分母為 0，例如該供應商期間內沒有已收齊的明細 |
| 合計列是空的 | 混了不同幣別或單位，不能加總，表格下方會註明 |
| 切換角色沒反應 | 正在編輯儀表板，先按「完成」或「取消」 |
| 看不到「角色儀表板管理」 | 只有管理員看得到，把角色切成「管理員」 |

> 畫面上的資料都是程式產生的虛構資料。
