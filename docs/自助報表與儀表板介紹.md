# 自助報表與儀表板：功能介紹

> 示範站的資料都是虛構的，由程式自動產生。

## 一句話說明

每個主管一打開就看到自己那份儀表板：業務看接單與交期，生產看完工、積壓與稼動，採購看金額、準時率與逾期未到，老闆看各部門摘要。想看更細，可以點進明細，或自己組報表，不用寫 SQL、不用找 IT。

## 四個角色的預設儀表板

| 角色 | 儀表板 | 主要內容 |
|---|---|---|
| 業務主管 | 營運總覽 | 接單金額、不重複訂單數、達交率、逾期未交、月別接單／出貨、客戶別接單、交期狀態分布 |
| 生產主管 | 生產總覽 | 上週完工零件／製程數、上週報工機時、積壓製程、近 8 週報工機時、機台稼動率最忙／最閒 10 台、報工類別占比、在製工令進度、久未動製程 |
| 採購主管 | 採購總覽 | 本月採購金額與單數、逾期未到筆數、供應商準時率、月別採購金額、供應商金額排行（含累計占比）、準時率排行、逾期未到明細 |
| 老闆 | 經營總覽 | 接單、達交率、逾期未交、本週報工機時（與前 4 週比較）、本月採購金額、逾期未到採購，每張卡都能一鍵開啟對應部門的儀表板 |

左上角可以臨時切換角色，看其他角色的畫面。

## 預設版與個人版

- 儀表板由管理員預先建好、指派給角色。
- 主管自己調整（換卡片、改排序、改選項）時，系統會另存成**個人版**，選單上標「已調整」，不影響其他人。
- 管理員之後更新預設版，**不會覆蓋**個人版；個人版上會出現「角色儀表板已更新」的提示，可以按「還原成角色預設」改回最新預設。
- 角色儀表板上的日期等篩選可以隨手改來看，但不會存下來；要保留就存成個人版。

## 管理員能做什麼

- 「角色儀表板管理」：新增、複製、刪除儀表板，勾選要指派的角色，設定每個角色的首頁。
- 建立共用報表：存報表時勾「設為共用報表」，所有角色都看得到；其他人可以「另存一份」自己改。

## 資料主題

| 主題 | 每一列代表 | 可算的比率 |
|---|---|---|
| 訂單明細 | 一筆訂單明細（一個品項） | 達交率 |
| 出貨明細 | 一筆出貨明細 | — |
| 工令製程 | 一道製程（一個工令零件的一個加工步驟） | 製程完工比 |
| 工令零件 | 一個工令零件 | 工令進度 |
| 報工明細 | 一筆報工紀錄 | — |
| 機台日稼動 | 一台機台的一天（依工作日曆） | 稼動率 |
| 採購明細 | 一筆採購明細（一個品項） | 供應商準時率 |
| 收料明細 | 一筆收料明細 | — |

「每一列代表什麼」決定了數字怎麼加。例如一筆訂單明細可能分好幾次出貨，在「出貨明細」裡加總訂購數量就會重複計算，所以畫面會擋下並說明原因。

## 自己組報表與圖表

報表設計器分五步：選資料 → 選欄位 → 設條件 → 分組與彙總 → 預覽與儲存。需要時可以勾選「相關資料」（例如採購明細加上收料結果）帶出更多欄位，列數不會因此變多。

報表可以轉成指標卡、折線、長條、環圈或表格。圖表的數字直接取自報表，兩邊一定對得上。每張卡片的「選項」可以設定：

- **排序與只看前幾名**（例如稼動率最閒 10 台）
- **累計占比**（長條圖加一條累計百分比線，看前幾家供應商占多少）
- **與前幾期比較**（指標卡顯示比前 N 週／月平均高或低多少）
- **卡片自己的日期區間**（上週、本週、本月、近 8 週、近 12 個月、今年……）
- **連結儀表板**（卡片下方出現「開啟『X』→」）

點長條或指標卡可以下鑽到組成這個數字的每一筆明細。

## 使用前要知道的事

### 金額與幣別

- **本幣金額**已換算，可以直接加總。
- **原幣金額**和**數量**只有依幣別／單位分組，或篩成單一幣別／單位時才能加總；被擋下時畫面會提供一鍵解法。
- 收料明細不提供金額（各幣別換算口徑不一致），採購金額請看採購明細。

### 交期、準時率、稼動率

- **達交率**（業務）：實交日＝第一次出貨日，達交率＝（如期＋提早）÷ 已到期筆數。
- **供應商準時率**（採購）：只算已收齊的明細，收齊時的末次收料日不晚於預交日即準時，依實交日歸期。已結案但沒收齊的明細另列「結案未收齊」，不算逾期。
- **稼動率**（生產）：報工機時 ÷ 應有產能，分母含沒有報工的機台，只算到資料基準日。看排行與機台群組比較有意義。
- 比率不能加總或平均，每個分組都重新計算；分母為 0 時顯示「—」。
- 取消的訂單一律不納入。

### 資料時間與重新整理

- 畫面上方顯示**資料基準日**與**資料時間**（這份數字是幾點從資料庫抓的）。
- 查詢結果會保留 10 分鐘。要重新查詢按「重新整理」，每人每分鐘一次。
